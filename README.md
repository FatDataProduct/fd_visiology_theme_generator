## Что это и зачем

Темы в Visiology хранятся в виде JSON-файлов с глубокой вложенной структурой, содержащей цвета в формате `rgba(r, g, b, a)`, флаги отображения, настройки шрифтов и стилей рамок для каждого типа виджета. Редактировать их вручную — долго и легко ошибиться.

**FatData Visiology Report Builder (VTB)** решает эту проблему:

- Генерирует гармоничные цветовые палитры из одного «seed»-цвета по 8 математическим моделям цветовых гармоний
- Позволяет точно настроить каждый аспект внешнего вида через понятный UI
- Мгновенно показывает результат на живом SVG-макете дашборда
- Экспортирует готовый валидный JSON, который Visiology принимает без изменений

## Левая панель — Палитра и глобальные токены

### Генератор палитры

Вся цветовая схема строится от одного **seed-цвета** (исходного цвета). Генератор автоматически создаёт до **10 гармоничных цветов** по выбранной математической модели.

#### Методы цветовой гармонии

| Метод | Описание |
|---|---|
| **Monochromatic** | Один оттенок, вариации по яркости (светлее → темнее) |
| **Complementary** | Два взаимодополняющих цвета (противоположные на цветовом круге, +180°) |
| **Split Complementary** | Основной цвет + два соседних к дополнительному (+150° и +210°) |
| **Triadic** | Три цвета, равномерно распределённых по кругу (+120°, +240°) |
| **Square** | Четыре цвета через каждые 90° по кругу |
| **Hexadic** | Шесть цветов через каждые 60° — максимальное разнообразие |
| **Analogous** | Три близких цвета (сдвиг ±30° от основного) — мягкая гамма |
| **Accented Analogous** | Аналогичные + яркий акцентный цвет на +180° |

> **Как работает генерация:** алгоритм парсит seed-цвет в пространство HSL (Hue, Saturation, Lightness), применяет смещения углов по выбранному методу, затем равномерно распределяет варианты по шкале яркости. Добавляется случайное смещение оттенка (0–360°) — поэтому каждое нажатие «Generate» даёт уникальный результат.

#### Параметры уточнения (Refinement)

После генерации можно скорректировать все цвета палитры одновременно с помощью слайдеров:

| Параметр | Диапазон | Действие |
|---|---|---|
| **Brightness** | −50 … +50 | Сдвигает яркость (L в HSL) |
| **Saturation** | −50 … +50 | Увеличивает или уменьшает насыщенность (S в HSL) |
| **Hue Shift** | −180 … +180 | Сдвигает все оттенки по цветовому кругу |
| **Temperature** | −50 … +50 | Смещает в тёплую (к красному) или холодную (к синему) сторону |

#### Блокировка цветов

Рядом с каждым цветом есть иконка **замка**. Заблокированный цвет не меняется при повторной генерации и при применении Refinement. Это позволяет зафиксировать, например, фирменный акцентный цвет и подбирать остальные вокруг него.

#### Ручная правка цветов

Каждый цвет можно изменить вручную:
- Кликнуть на цветовой квадрат → откроется системный color picker
- Внутренний формат хранения — `rgba(r, g, b, a)` (R, G, B от 0 до 255, Alpha от 0 до 1)

### Размер палитры

Ползунок **Palette Size** регулирует количество генерируемых цветов (от 3 до 10). При экспорте палитра автоматически дополняется до 10 позиций нейтральными тёмными оттенками, производными от seed-цвета.

### Глобальные токены (Global Tokens)

Токены применяются ко **всем виджетам** одновременно:

| Токен | По умолчанию | Описание |
|---|---|---|
| **Title Font Family** | Arial | Шрифт заголовков виджетов |
| **Data Font Family** | Open Sans | Шрифт подписей данных |
| **Title Font Size** | 21 | Размер шрифта заголовка (px) |
| **Line Height** | 1.5 | Межстрочный интервал |
| **Border Radius** | 3 | Скругление углов рамок (px) |

## Импорт и экспорт JSON

### Импорт существующей темы

1. Нажмите кнопку **Import JSON** в верхней панели
2. Выберите `.json`-файл темы Visiology
3. Приложение распарсит файл, автоматически извлечёт палитру из `DataColors.$values` и загрузит все настройки
4. Все поля становятся редактируемыми

> При импорте сбрасываются: режим Light/Dark, Refinement, Lock-состояния.  
> Название темы берётся из поля `Name` в JSON.

### Экспорт темы

1. При необходимости измените название темы в поле ввода (TopBar)
2. Нажмите **Export JSON**
3. Приложение:
   - Применяет все изменения палитры, токенов и настроек виджетов
   - Дополняет палитру до 10 цветов нейтральными оттенками (если < 10)
   - Проставляет `ZIndex` для каждого стиля виджета
   - Запускает валидацию (наличие обязательных полей `$type`, структуры `WidgetStyles`)
   - Скачивает файл `<название-темы>.json`

### Формат экспортируемого файла

Файл полностью совместим с Visiology: сохраняются все пространства имён `$type`, структура `WidgetStyles.$values`, `DataColors.$values` и прочие служебные поля.

## Работа с формулами и цветовыми выражениями

### Формат цветов в JSON

Все цвета в теме Visiology хранятся в строковом формате `rgba`:

```
rgba(R, G, B, A)
```

где:
- `R`, `G`, `B` — целые числа от **0 до 255**
- `A` — прозрачность, дробное число от **0** (полностью прозрачный) до **1** (полностью непрозрачный)

Примеры:
```
rgba(40, 238, 150, 1)    — непрозрачный зелёный
rgba(255, 255, 255, 0)   — полностью прозрачный белый (нет фона)
rgba(30, 30, 46, 0.95)   — почти непрозрачный тёмно-синий (dark mode)
rgba(0, 0, 0, 0.3)       — полупрозрачная чёрная тень
```

### Конвертация HEX ↔ RGBA

Для ручного редактирования JSON полезно знать формулу конвертации:

**HEX → RGBA:**
```
#RRGGBB  →  rgba(parseInt(RR,16), parseInt(GG,16), parseInt(BB,16), 1)
```

Пример в Excel:
```excel
=CONCATENATE("rgba(",HEX2DEC(MID(A1,2,2)),", ",HEX2DEC(MID(A1,4,2)),", ",HEX2DEC(MID(A1,6,2)),", 1)")
```
> Здесь `A1` содержит цвет в формате `#RRGGBB` (например, `#1CA3E0`).

**RGBA → HEX:**
```
rgba(R, G, B, A)  →  #(DEC2HEX(R))(DEC2HEX(G))(DEC2HEX(B))
```

Пример в Excel (для разбора rgba-строки вида `rgba(40, 238, 150, 1)`):
```excel
=CONCATENATE("#",
  TEXT(DEC2HEX(VALUE(TRIM(MID(SUBSTITUTE(A1,",",REPT(" ",100)),101,100)))),"00"),
  TEXT(DEC2HEX(VALUE(TRIM(MID(SUBSTITUTE(A1,",",REPT(" ",100)),201,100)))),"00"),
  TEXT(DEC2HEX(VALUE(TRIM(LEFT(SUBSTITUTE(MID(SUBSTITUTE(A1,",",REPT(" ",100)),301,100),")",REPT(" ",100)),100)))),"00")
)
```

> Эти Excel-формулы удобны при массовой подготовке цветовых схем во внешних таблицах перед импортом в VTB.

### Работа с палитрой в Excel / Google Sheets

Если вы готовите цветовую схему в таблицах, удобный шаблон для столбцов:

| Столбец | Содержимое | Пример |
|---|---|---|
| A | HEX-цвет | `#1CA3E0` |
| B | R-компонент | `=HEX2DEC(MID(A2,2,2))` |
| C | G-компонент | `=HEX2DEC(MID(A2,4,2))` |
| D | B-компонент | `=HEX2DEC(MID(A2,6,2))` |
| E | rgba-строка для Visiology | `=CONCATENATE("rgba(",B2,", ",C2,", ",D2,", 1)")` |

Скопируйте готовые `rgba`-значения из столбца E и вставьте их вручную в экспортированный JSON (или введите в color picker приложения через ввод hex-кода).

### Формула расчёта контрастности (WCAG)

Приложение использует WCAG-совместимый подход при инверсии Light → Dark. Для проверки контраста цвета текста на фоне в Excel:

```excel
=IF((0.299*B2 + 0.587*C2 + 0.114*D2)/255 > 0.5, "Тёмный текст", "Светлый текст")
```

Где `B2`, `C2`, `D2` — R, G, B компоненты фонового цвета. Значение > 0.5 означает светлый фон → нужен тёмный текст.

### Прозрачность фона виджета

Alpha-канал в `rgba` позволяет делать виджеты полупрозрачными. Полезные значения:

| Alpha | Эффект |
|---|---|
| `0` | Полностью прозрачный (фон дашборда виден насквозь) |
| `0.05–0.15` | Лёгкая тонировка |
| `0.7–0.9` | Полупрозрачный блок |
| `1` | Полностью непрозрачный |

## Структура JSON-темы Visiology

Экспортируемый JSON имеет следующую верхнеуровневую структуру:

```json
{
  "$type": "...",
  "Name": "Название темы",
  "DataColors": {
    "$type": "...",
    "$values": [
      { "$type": "...", "Color": "rgba(40, 238, 150, 1)", "Name": "Color 1" },
      ...
    ]
  },
  "WidgetStyles": {
    "$type": "...",
    "$values": [
      {
        "$type": "...",
        "Type": "BarChart",
        "ZIndex": 0,
        "Title": { "TextStyle": { "FontFamily": "Arial", "FontSize": 21, ... } },
        "Frame": { "Style": { "Radius": 3, ... } },
        "Background": { "Color": { "Color": "rgba(255,255,255,0)" } },
        "YAxis": { "Enabled": true, ... },
        "XAxis": { "Enabled": true, ... },
        "Legend": { "Enabled": true, ... },
        ...
      },
      ...
    ]
  }
}
```

Поддерживаемые типы виджетов в `WidgetStyles`:
- `BarChart` — горизонтальная гистограмма
- `ColumnChart` — вертикальная гистограмма
- `LineChart` — линейный график
- `PieChart` — круговая диаграмма
- `GaugeChart` — индикатор
- `Indicator` — KPI-плашка
- `Table` — таблица
- `Filter` — виджет фильтра

### Ключевые модули

**`themeStore.ts`** — Zustand-стор, хранящий всё состояние:
- `theme` — текущий объект темы (VisiologyTheme)
- `palette` — массив PaletteColor (до 10 цветов)
- `seedColor` — исходный цвет для генерации
- `harmonyMethod` — выбранный метод гармонии
- `refinement` — параметры уточнения (brightness/saturation/hueShift/temperature)
- `lockedIndices` — Set заблокированных цветов
- `globalTokens` — глобальные токены шрифтов и радиусов
- `mode` — 'light' | 'dark'

**`paletteGen.ts`** — генерация палитры:
- `generatePaletteFromSeed(seedHex, method, count)` — основная функция генерации
- `applyRefinement(palette, refinement, lockedIndices)` — применение корректировок
- `fillPaletteTo10(palette, seedHex)` — дополнение до 10 цветов для экспорта
- `rgbaToHex(rgba)` / `hexToRgba(hex, alpha)` — конвертация форматов

**`exporter.ts`** — экспорт:
- `validateTheme(theme)` — проверка обязательных полей и `$type`-пространств
- `applyPaletteToTheme(theme, palette)` — запись цветов палитры в `DataColors`
- `downloadTheme(theme, name)` — скачивание JSON-файла

**`importer.ts`** — импорт:
- `importThemeFromJson(text)` — парсинг JSON, извлечение палитры, валидация
